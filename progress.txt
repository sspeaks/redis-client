## Codebase Patterns
- New Redis commands require changes in 3 places: typeclass in Command.hs, RedisCommandClient instance in Command.hs, ClusterCommandClient instance in Client.hs
- Single-node commands use `executeCommandAs [args]`, cluster keyed commands use `executeKeyedAs key [args]`
- Use `showBS` to convert Int/Double to ByteString for Redis args
- Cluster multi-key commands (lists of keys) need a `case keys of [] -> executeKeyless ...; (k:_) -> executeKeyedAs k ...` pattern
- Build with `nix-shell --run 'cabal build all'` to verify changes
- A pre-commit hook runs stylish-haskell on changed .hs files
- New typeclass methods also need implementations in StandaloneCommandClient (Standalone.hs), not just Command.hs and Cluster/Client.hs
